# property-browser

Thư viện property browser cho Qt 6 Widgets (namespace `qpb`): khai báo thuộc tính một lần,
hiển thị dạng Tree / List / Form trên cùng một `QAbstractItemModel`, mở rộng kiểu dữ liệu mà không sửa lib.
