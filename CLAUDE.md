# Project conventions

- Code, comments, commit messages and documentation are written in **English**.
- Files with a `-vi` suffix (e.g. `docs/SPEC-vi.md`) are Vietnamese reference translations. The English files are
  authoritative; when an English doc changes, update the matching `-vi` file in the same change.
- Chat with the maintainer is in Vietnamese.
- Specification: `docs/SPEC.md`. Plan and task IDs (M0.1, M1.2, ...): `docs/PLAN.md`.
- `qpb/` is the distributable component folder; follow SPEC §6.3 for anything under it and SPEC §9 for public headers.
